**Lab 4 Summary: Data Structures**



In this lab, I learned how to use Python’s main data structures—lists, tuples, sets, and dictionaries—to organize and manage data for different tasks. I worked on exercises like analyzing prices, handling geographic coordinates, comparing student groups, calculating employee payroll, summarizing sales, and building an inventory system for a store. The main goals were organizing data clearly, performing calculations, and keeping track of unique items.



**What I Learned:**



**1.Lists:**



* Lists store a series of items in order, like product prices or products in a category.
* They allow sorting, filtering, and finding averages or totals easily.

Example: Filtering expensive items from a price list.



**2.Tuples:**



* Tuples store data that should not be changed, like geographic coordinates or product information (name, price, quantity).
* They are immutable, which helps keep important data safe.

Example: Latitude and longitude pairs for locations.



**3.Sets:**



* Sets store unique items only, like student names or product names across categories.
* They make it easy to find common items, combine items, and remove duplicates automatically.

Example: Finding students who are in both Python and ML courses.



**4.Dictionaries:**



* Dictionaries map keys to values, like employee IDs to employee details, or category names to products.
* They are very useful for organizing data in a structured way and fast lookup.

Example: Calculating total payroll or total revenue for each product category.



**Challenges I Faced:**



* Tuples cannot be changed directly, so updating quantities needed creating new tuples.
* Nested structures (lists of tuples inside dictionaries) were a bit tricky to loop through.
* Ensuring unique product names across categories required using sets carefully.
* Calculating totals for payroll, sales, and inventory needed careful loops and accumulation.
